# 0992 — `uses` takes a braced list and an alias, and a name clash is reported only where the name is written

- **Status:** Accepted (v0.727)

**Context.** `uses` had one form, the whole commons. Two used commons that declared one name could not be used together even when the file never wrote the name, and there was no way round it: `consumes` has braced and aliased forms, `uses` had neither. Libraries naming common things (`Status`, `Id`, `Error`) is normal.

**Decision.** (A) The forms mirror `consumes`: `uses lib.y { Status as YStatus, describe }` selects names, renaming any of them (a type, function, constant, asset or embed; renaming a type leaves its variants' names as they are), and `uses lib.y as Y` makes the commons' public names reachable as `Y.Status` and `Y.describe(…)` and not bare. A name that is not public is `bynk.uses.unknown_name`. (B) Two used commons that declare one name are legal. Writing the name bare is `bynk.uses.ambiguous_name`, listing the qualified spellings; a declaration of the unit's own still takes precedence, as does a `private` one never being imported. `bynk.uses.name_conflict` stays for the shadowed-crossing cases it already served, and its explanation is narrowed to them. (C) A qualified name is `Y.Status` by an alias and `lib.y.Status` by the commons' full name. Departure: a declaration is reached by one spelling in a unit. A type's identity in the checker is its name, so a second spelling of the same declaration (`Status` from a selection beside `lib.y.Status`) would be a second type, and a canonicalisation pass that rewrites every spelling to one needs an AST walker over every expression, pattern and type position, which does not exist. Reading a declaration by a second spelling is `bynk.uses.second_spelling`, naming the spelling to keep; a clash is never two types. Full Decision C is a follow-up. A one-segment commons name (`uses keys`) is not a qualifier, so `keys.map(…)` stays a method call on a local. (D) Variants follow the existing shared-variant rules, unchanged.

Each `uses` clause gives its unit a per-unit view of the used commons' public table: selected and renamed declarations filed under the spelling used, and every type reference inside them renamed to match, so the composers that read a used table need no rules of their own. The emitter imports a renamed name as `{ Status as YStatus }`, an alias as `import * as Y`, and a full-name qualifier as a private namespace import hung on a TypeScript `namespace`.

**Consequences.** No program that checked before stops checking: the early error at the `uses` line was the only thing two whole `uses` of a clashing name ever produced, and it is now reported where the name is written. A file that never writes the name now compiles. Hover names the commons a used name comes from and semantic tokens colour an alias as a namespace; completion inside `uses U { }` and the code actions on `ambiguous_name` follow in the tooling increment.
