# 1042 — One Route verdict combines forwards, a reply and tags, applied reply first with partial failure handled

- **Status:** Accepted (v0.779)

**Context.** #3887. A handler made one decision per message, though Cloudflare allows several `forward()` calls, a forward and a reply on one message, and `X-` headers on a forward. "Send to billing and acknowledge the customer" could not be expressed, and ADR 0805 B had anticipated a combining verdict.

**Decision.** (A) One general variant, `Route(actions: EmailActions)`, rather than `ForwardAll`, `ForwardAndReply` and the combinations; `Forward(to)` and `Reply(m)` stay as shorthands, and an empty `Route` behaves as `Accept`. `EmailActions` is `{ forward: List[String] = [], reply: Option[EmailReply] = None, tag: Map[String, String] = Map.empty() }`. (B) The reply is applied first, then each destination, de-duplicated without regard to case; each refusal is logged with its class name; if every action is refused the message is rejected with today's reason for the first refusal, and if at least one succeeds it is handled, because a forward cannot be taken back and rejecting after one would mislead the sender. (C) At most 20 distinct destinations: more is a handler fault, settled as one (and forwarded by a declared `fallback`). (D) Each `tag` name starts with `X-` and holds only letters, digits and `-`, and each value has no CR or LF; a literal map that breaks this is `bynk.email.bad_tag`, a run-time bad entry is dropped and logged by name only and never written, and tags apply to forwards only because a reply's headers are the runtime's. (E) Deploy's verified-destination warning extends to the literal elements of a `Route`'s `forward`, and a list built at run time is the existing computed-destination note.

**Consequences.** A user's exhaustive `match` on `EmailVerdict` gains an arm, which the changelog notes. A user's own variant named `Route` is disambiguated by `EmailVerdict.Route`. The `system` harness reports what the entry did as the verdict that names it: one forward or a lone reply as `Forward`/`Reply`, anything combined or tagged as a `Route` whose tag names are lower case, since `Headers` lower-cases them.
