## ADR: vectorize-typed-reads
title: Typed Vectorize reads are compiler-lowered over the text operations, with a Result per match
summary: Why the failure is per match and not the whole-reply policy of a declared typed read, and what the call lowers to

**Context.** `upsertValue[M]` writes typed metadata, but `query` and `getByIds` return it as text, so every caller decodes every match by hand. The text was kept for a sound reason: a vector written by an older version of the program should be skippable or repairable, not fault the whole query (#4101).

**Decision.** `queryValue[M](vector, options)` and `getByIdsValue[M](ids)` on a derived `Vectorize` instance return `Effect[Result[List[VectorMatchOf[M]], VectorError]]` (`List[VectorReadOf[M]]` for `getByIdsValue`, which has no score), where `metadata` is `Option[Result[M, DecodeError]]`: `None` for no metadata or `returnMetadata: Omit`, `Some(Ok(m))`, or `Some(Err(e))` for metadata that does not read as `M`. They are not declared operations (ADR 0830's typed reads have a fault or miss policy for a whole reply, and the failure here is per match): the checker records `Callee::VectorValueRead` and the emitter lowers the call over `query` or `getByIds` as written, then reads each match's metadata text with the ordinary JSON decoder, the encoding `upsertValue` writes. So the binding, the in-memory index and a test's `stub Docs.query(…)` are all unchanged and all feed the typed read. A `DecodeError` names the path and expectation, but its message can quote part of the stored value (the JSON parser's own text, a number that is not a safe integer), so it is not logged unredacted. The text operations stay for metadata written outside Bynk. `M` must be `Codable`. `getByIdsValue`'s result type, `VectorReadOf[M]` (a `Vector` with typed metadata), is the issue's `getByIdsValue` left unnamed there. Experimental with `Vectorize`.

**Consequences.** An `Indexed` read returns only the filterable properties and decodes as `M` only when `M` has just those fields; the docs advise `All` with typed reads. A stale vector is one `Err`, the rest read.
