## ADR: consumer-built-context-types
title: A consumer builds a context's transparent types itself
summary: a consumer lowers `.of` and a sum variant of a consumed context's type inline, so no value import crosses the Worker boundary, and the checker's adapter-only qualification goes

**Context.** The maintainer's ruling on #3948 is that a transparent type is constructible outside its owner and an opaque one is not. #4212 applied it to a type an adapter exports, because an adapter is linked into every consumer. A context-owned type was left with the old rule: under Workers a consumer imports a consumed context's types as types only (#661), so `Port.of(n)` or `Shape.Circle(r)` emitted a value reference to an export the callee's `handlers.ts` does not have, and `tsc` rejected it.

**Decision.** The consumer builds the value itself, the way it already builds the codecs of a consumed type. A bare or qualified variant of a consumed sum is a tagged literal cast to the type (the #2045 form, which only handlers used so far and which a free function or method now reaches too, through the project facts the module context is built from). `T.of(x)` on a consumed refined type is an immediately invoked copy of the owner's `of` (the same guards, from one shared builder), so the check runs in this Worker. Records already lowered inline. The checker drops the adapter-only exception: a `transparent` export of either kind takes `.of`, a variant and a record literal from a consumer, while an opaque export, a declared `opaque` type and `.unsafe` on any type stay the owner's.

**Consequences.** Programs that were refused with `bynk.context.external_construction` for a context's transparent type now compile; the code remains for opaque exports and `.unsafe`. The check text is duplicated into the consumer's module, bounded by the types it builds. The five existing negative fixtures for this code and its explain example now export the type `opaque`, which is what they were about. The Workers emission of a consumer that built a consumed sum from a free function changes from `Shape.Circle(r)` to the inline literal.
