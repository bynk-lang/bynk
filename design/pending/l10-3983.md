## ADR: effectful-suite-helpers
title: A suite helper may declare given and run effects with the case's capabilities
summary: Which helpers may be effectful, where they may be called, which tiers allow them, and how they get their capabilities

**Context.** A suite helper had to be pure, so setup that runs effects (create a table, seed rows, open a session) was written out in every case that needed it (#3983).

**Decision.** The maintainer accepted the issue's decisions. A: a suite helper may return an `Effect` and declare `given`, as a context function does; an implicit `setup { }` block was rejected because it hides what each case depends on. A helper that returns an `Effect` without `given` stays `bynk.suite.fn_effectful`, whose note now gives the `given` form. B: a helper is called from a `case` or `property` body and from another helper, which declares the capabilities it passes on (`bynk.given.missing_for_call`); a `stub … returns` value cannot call one (`bynk.given.missing_for_call`, since a stub supplies a value and never runs logic). A case's capabilities satisfy the helper's `given` without the case declaring them. C: at `unit` and `integration`, `given` names the target's capabilities (its own, and its consumed adapters' and services'), and the case's stubs and call recording apply inside the helper, because the helper takes the case's own `deps`. At `system` a case names no capability, so a `given` helper in a `system` suite is `bynk.test.helper_given_at_system`. D: a fault in a helper fails the case as it would inline, and `expect` stays case-only.

The emitted helper takes the case's `deps` as a hidden parameter, as a context function with `given` does, and the test module aliases each capability type it names to the target's namespace (`type Meter = __ns_demo_desk.Meter`).

**Consequences.** Departure: the issue also lets a `system` helper be effectful through the addresses a system case uses, with no `given`; that is not part of this change, so such a helper is still `bynk.suite.fn_effectful`. Effectful helpers are per suite; sharing them across suites is #3984.
