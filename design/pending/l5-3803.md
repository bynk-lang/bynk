## ADR: agent-state-write-value-types
title: Each store write in the agent state model carries the type it stores
summary: A write in `bynk/agentStateModel`'s effects gains `valueType`, `fieldType`, and `valueRef`/`fieldRef` into the wire contract's own type table, read from the field's declared kind

**Context.** #3803. The agent state model gave each handler's `store` writes as a field and an operation, but not the type of the value written, so a client could not tell whether a write puts something unbounded (`Bytes`, a `List`, a `Map`, a long `String`) into Durable Object storage, which caps a key and value at 8 MB for SQLite-backed classes and 128 KiB for legacy KV-backed ones. The VS Code extension's platform-limit hints could not flag agent `store` writes at all.

**Decision.** (A) A write carries the type of the stored value after the write, read from the field's declared store kind, which is the checker's own answer and needs no inference: a cell's `T` for `:=` and `update`, a map's or cache's `V` for `put` and `update`, a set's `T` for `add`, a log's `T` for `append`. For `append`, `put` and `add` it reports both the element (`valueType`) and the field's resulting collection type (`fieldType`, `Map[String, Order]`); for a cell `fieldType` is the cell's `T`. A `remove` stores no value, so it has no `valueType` and still says what the field is. (B) The types are shared with `bynk/wireContract`, not re-rendered: names are shown as the wire contract shows them, a reference is the wire contract's own `WcRef` (`Named`, `Inst` with its codec key, `Bytes`, `Base`), and the response carries the same `types` and `instantiations` table, built by the same walk the emitter uses over an agent's `store` types, so a client reuses one size classifier.

**Consequences.** Additive for a client: every new field is omitted when it has no value, and an older client ignores them. The write's `fieldRef` is only given for a cell, whose field type is a value type, since a collection has no wire shape of its own. The extension's platform-limit hints can now classify an agent write; that is a change in `vscode-bynk`, not here.
