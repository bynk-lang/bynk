refactor(emit): `is`, the short-circuit operators and `par` lower to nodes (1A.14)

`lower_is` builds a node over the receiver path: the tag, literal, range, record, list and or-pattern tests (`pattern_tests`, joined by `and_join`) and the identity-arrow wrapper for a tag test (#2836). `is_receiver_ref` returns a node, and the receiver temporary is a `const` (or, inside a hoisting right operand, an in-place assignment) statement node. `emit_is_test_bindings` returns statements: a record field, a list element or rest and the refined narrowing cast are `Const` nodes, a variant payload read keeps its `Extract<typeof …>` cast as text (`bynk_ts` has no `typeof` or literal type node), and an or-pattern's `let` and `if`/`else` dispatch stays text. `&&`, `||` and `implies` build `Binary` nodes (`implies` keeps `Paren(Binary(Or, Unary(Not, Paren(l)), r))`); a right operand that hoists, or an `is` binding, goes in a compact `Block` arrow IIFE, and a `?` in it hoists a `let slot: boolean; if … else …` statement pair built from nodes (`hoisted_if_nodes`, now shared with the value-position `if`). Each is a node only when every part is a node and each statement and the value print on one line; otherwise today's text, byte for byte. The text form `pattern_match_tests` is deleted.

`par` builds `const [a, b] = await __bynkSettleAll([...]);` over thunk arrows. A thunk is `async` when its part's lowering awaited (`emitted_await`, saved and restored around each part), not when its hoisted text contains `"await "`: no fixture in the corpus disagrees, and a string literal containing `await ` now stays synchronous. A multi-line `par` (any part hoisted) prints its items at the printer's depth rather than one column in; no fixture has one, so no golden changes. `bynk_ts` gains `TsBindingName::ArrayPattern` and `TsExpr::LinesArray` (an array broken one item per line wherever it sits, as `Array { multiline: true }` does only as a statement initialiser). The compact `{ s1; s2; }` arrow body Decision B of #3715 asked for already exists as `TsArrowBody::Block`, so no `InlineBlock` variant is added; the printer tests pin it with a `const` and a `return`.

Stays text: a refined-type `is` check (`refined_check_as_bool`, which `bynk_ts::predicate` does not build as a node), a variant payload binding, an or-pattern's dispatch lines, the hoisted `let tmp!: T;` declaration of an `is` receiver temporary (no definite-assignment `let` in `bynk_ts`), and any short-circuit operand that is itself text. Also folds in the 1A.13 review nits (a comment at the compact-statements `depth + 1` call, and tests for a guarded value-position `match` and a list pattern's `path[i]` and `..rest`).

Gated probes: `ts_writes` (1460 to 1451), `lowering_text_bridge` (111 to 89) and `stmt_text_lines` (40 to 32) fall. Goldens, source maps and the run fixtures are unchanged.
