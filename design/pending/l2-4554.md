changelog: An agent call's request body to a Durable Object no longer carries the caller's compose-private `deps` entries, so a `SignedCookie` actor's signing keys (`secret` and `previous`) are not sent to the Durable Object, where a tail worker or request log could read them; every `__`-prefixed `deps` key is now dropped from the wire unless it is explicitly marked wire-safe, so the next secret-bearing entry is private by default
