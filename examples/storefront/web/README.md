# Storefront web

A framework-free front end for the `storefront` Bynk service. `src/api.ts` is
generated by `bynk client` (see `[build.client]` in `../bynk.toml`) and committed;
`src/storefront.ts` is the logic over it.

```sh
bynk client --check     # fails when src/api.ts is stale (run it in CI)
bynk client             # regenerate it
tsc -p web              # type-check the front end
```
