> **what compiles today** on the development line, `main`; planned features

> [Versioning & roadmap](/project/versioning-and-roadmap/).

> latest one.

Welcome to the official guide and reference for **Bynk** — a statically typed,
architecture-first language that compiles to typed TypeScript for Cloudflare
Workers.

The book has four parts to read:

- **[Start](/book/introduction/what-is-bynk/)** — what Bynk is, why it exists,
  and how to install it.
- **[Learn Bynk](/book/tutorials/first-program/)** — a tutorial that builds
  one service, chapter by chapter. Read it in order.
- **[Concepts](/book/concepts/)** — the ideas behind each part
  of the language: why it works the way it does.
- **[Guides](/book/guides/)** — how to do a particular task, grouped by what
  you are building.

And three to look things up in:

- **[Reference](/reference/)** — the exact rules of the language and its
  tooling.
- **[Specification](/reference/spec/)** — the normative definition of the
  language.
- **[Diagnostic index](/reference/diagnostics/)** — every error the compiler
  reports, with a page for each saying what it means and how to fix it.

Each page does one of those jobs, following [Diátaxis](https://diataxis.fr/):
a tutorial teaches, a concept explains, a guide gets a task done, and the
reference states the rules.

If you are not sure where to start:

- **New to Bynk?** Read [What is Bynk?](/book/introduction/what-is-bynk/), then
  work through [Learn Bynk](/book/tutorials/first-program/) in order.
- **Coming from TypeScript?** Read
  [Coming from TypeScript](/book/introduction/coming-from-typescript/).
- **Evaluating Bynk?** Read [Why Bynk exists](/book/introduction/what-is-bynk/#why-bynk-exists),
  then [Bynk compared to TypeScript](/book/concepts/about/bynk-compared-to-typescript/).
- **Have a specific task?** Go to the [Guides](/book/guides/).

> [!NOTE]
> Meet an unfamiliar term? The [glossary](/reference/glossary/) defines Bynk's
