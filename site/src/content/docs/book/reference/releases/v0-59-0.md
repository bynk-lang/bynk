Released on 20 June 2026 as **v0.59.0**, with one increment, v0.59.
See [Upgrading](/book/reference/upgrading/) for what to change when you move to it.

| Version | Highlights |
|---|---|
| **v0.59** | **`bynkc test --format json` and a VS Code Test Explorer** (tooling; proposal v0.59). `bynkc test` gains a `--format` selector (`rich` default | `json`); the human ✓ / ✗ output is structurally unchanged. **`--format json`** emits a single pinned JSON document — suites (each tagged `unit`/`integration`) of cases with `outcome`, and a failing case's `message` + structured `location` — with three terminal states distinguished on a closed `error.kind` (`compile` carries the `bynkc` diagnostic lines; `runtime` carries a crashed runner's stderr). The exit code follows the runner's process status, so a crash is never reported as success. Under the hood the generated runner emits NDJSON (an internal protocol the driver folds into the document). **Assertion locations are now real:** the `assert` lowering emits a project-relative **`path:line:col`** (it previously carried only a byte offset), for both unit and integration tests — so the human `assertion failed at …` line now names the file and position, and `--format json` consumers (and the editor) get click-through. The **VS Code extension** gains a **Test Explorer**: run Bynk tests from the Testing view or **Bynk: Run Tests**, with click-through from a failing assertion to its `.bynk` line and compile failures routed to the Problems panel. **No language surface** — tooling only. Deferred: per-test timing (`durationMs`), a pre-execution discovery document, and live NDJSON streaming. |
