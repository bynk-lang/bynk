| Version | Highlights |
|---|---|
| **v0.40.1** | **Fix: clicking the `N references` CodeLens** (#143) — the reference-count lens rendered but clicking it threw "argument does not match one of these constraints…". The lens carries the built-in `editor.action.showReferences` command, whose arguments the server sends as plain LSP JSON; VS Code validates them with `instanceof`, so the plain objects were rejected. Added a `provideCodeLenses` client middleware (`vscode-bynk`) that re-hydrates the `[uri, position, locations]` arguments into real `vscode.Uri` / `Position` / `Location[]` instances. Extension-only; no server change. |
