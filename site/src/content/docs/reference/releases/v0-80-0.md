Released on 24 June 2026 as **v0.80.0**, with one increment, v0.80.
See [Upgrading](/reference/upgrading/) for what to change when you move to it.

| Version | Highlights |
|---|---|
| **v0.80** | **Agent invariants** (language; ADR 0107). An agent may now declare **invariants** — universally-quantified predicates that must hold of every committed state: `invariant paid_has_payment_ref: status == Paid implies paymentRef.isSome()`. They sit in a phase between the `state { }` block and the handlers, and read state fields by bare name. A new lowest-precedence operator **`implies`** (`P implies Q` ≡ `!P || Q`, directional) joins `is` in the predicate language. Invariants are **runtime-checked at the commit boundary**: `commitState` evaluates each predicate against the proposed state before persisting it; a violation throws a dedicated **`InvariantViolation`** fault *before* the write, so the offending commit never lands (non-persistence of the offending commit — not whole-handler rollback). Well-formedness is enforced — `Bool`-typed (`bynk.invariant.not_bool`), pure (`bynk.invariant.impure_predicate`), agent-local (`bynk.invariant.cross_agent_reference`), uniquely named (`bynk.invariant.duplicate_name`). **MVP observability limit:** a violation surfaces as a 500 and in the logs (agent type + invariant name, never the key), not yet as a caller-distinguishable response. Two named follow-ons: the static provable-violation pass, and a general typed-agent-fault channel. |
