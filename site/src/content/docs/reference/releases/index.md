title: Releases
description: Every Bynk release, newest first, with the increments each one shipped.
---
Bynk is pre-1.0 and developed in small, spec-first increments (see
[Versioning & roadmap](/project/versioning-and-roadmap/)). This book is
written against **v0.673**, the development line on `main`, which can be
ahead of the latest release. An install gives you the latest release: the
first row of the table below.

Each increment gets a version when it merges. A **release** gathers the
increments merged since the one before it, and is published as a tagged
build. Before 1.0 a release is cut when a feature track retires; after 1.0,
each month. While Bynk is pre-1.0, increments may change behaviour: see
[Upgrading](/reference/upgrading/) for what to change.

The increments merged since the latest release are under
[Unreleased](/reference/releases/unreleased/).
