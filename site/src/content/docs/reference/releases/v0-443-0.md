---
title: v0.443.0
description: The increments released in Bynk v0.443.0.
---
Released on 30 October 2026 as **v0.443.0**, with the increments from v0.436.1 to v0.443.0.
See [Upgrading](/reference/upgrading/) for what to change when you move to it.

| Version | Highlights |
|---|---|
| **v0.443.0** | `Instant` reads and writes ISO-8601: `t.toIso()` gives RFC 3339 text in UTC (`YYYY-MM-DDTHH:mm:ss.sssZ`), and `Instant.fromIso(s)` reads the RFC 3339 date-time profile, converting an offset, as `Option[Instant]` (standard-library K3, [#2592](https://github.com/bynk-lang/bynk/issues/2592)) |
| **v0.442.0** | `bynk.cloudflare`'s `Kv` gains five experimental operations: `getWith` and `putWith` (metadata, a `Never`/`After`/`At` expiry, `cacheTtl`), `getBytes` and `putBytes` for binary values, and a paged `listPage` with each key's expiry and metadata; the platform's limits are checked before the call, and the existing operations are unchanged (standard-library P1, [#2590](https://github.com/bynk-lang/bynk/issues/2590)) |
| **v0.441.0** | `bynk`'s `Method` gains `Patch`, `Head` and `Options`; `Fetch.sendWith(req, FetchOptions { timeout, redirect })` adds a timeout (`Err(Timeout)` when it elapses) and a `Manual` redirect policy; `Logger` gains `warn`, `debug` and a structured `log(level, msg, fields)`. `sendWith` and `log` are experimental (standard-library K5a, [#2586](https://github.com/bynk-lang/bynk/issues/2586)) |
| **v0.440.0** | bynk/refinedTypeModel sends each clause's predicate in structured form, so a client checks a candidate without running JavaScript |
| **v0.439.0** | A `from queue("…")` consumer's name is checked against Cloudflare's queue-name rule (1–63 lowercase letters, digits or `-`, starting and ending alphanumeric); names Cloudflare would refuse at `wrangler queues create` are now a compile error |
| **v0.438.0** | `bynk.cloudflare` gains `Analytics`, a Workers Analytics Engine dataset as an instance-only derived capability with no options (`capability Signups = Analytics`), whose `write(DataPoint)` checks the platform's per-point limits before writing; `bynk deploy` derives the dataset's name in snake case (`shop_cart_signups`, `shop_cart_signups_staging`) and has nothing to create (standard-library P3b, [#2582](https://github.com/bynk-lang/bynk/issues/2582)) |
| **v0.437.1** | bynk deploy --prune no longer deletes a consumed queue the deploy only reused rather than created |
| **v0.437.0** | `bynk.cloudflare` gains `Queue`, a Cloudflare Queue producer as an instance-only derived capability (`capability OrderEvents = Queue @name("order-events")`) with `send`, `sendWith` (a delay) and `sendBatch` over JSON text from `Json.encode`; `bynk deploy` creates a missing producer queue, recording it only when it created it (standard-library P2, [#2578](https://github.com/bynk-lang/bynk/issues/2578)) |
| **v0.436.10** | The "Show capability path" command also sends each chain's sites, shared sites repeated, so a client can mark where one path ends |
| **v0.436.9** | Doc-link resolution goes through one context-aware resolver in `bynk-ide` (#2531) |
| **v0.436.8** | The documentation panel and the editor attach a method's doc links at the same place, its name (#2569) |
| **v0.436.7** | Type hierarchy can start from a built-in type such as `Int` anywhere it is written, including field and parameter types, not only as a declaration's base |
| **v0.436.6** | Doc-link completion after a unit prefix (`[window.`, `[a.b.`) offers that unit's top-level names |
| **v0.436.5** | Inline values while debugging now show for the locals of `suite` `case` and `property` blocks, not only functions and handlers |
| **v0.436.4** | `bynk test` checks declaration examples in a context's doc comments |
| **v0.436.3** | `bynk mcp`'s `bynk_describe_symbol` answers from the language server's full hover ladder |
| **v0.436.2** | The documentation panel resolves doc links in context, so a declaration's own fields, parameters and unit-qualified names link as they do in the editor |
| **v0.436.1** | The unresolved doc-link hint now flags a mistyped first-party link such as `[Clock.nwo]` and suggests `[Clock.now]` |
