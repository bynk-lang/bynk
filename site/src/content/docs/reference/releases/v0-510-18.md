Released on 6 November 2026 as **v0.510.18**, with the increments from v0.510.3 to v0.510.18.
See [Upgrading](/reference/upgrading/) for what to change when you move to it.

| Version | Highlights |
|---|---|
| **v0.510.18** | Crate hygiene D1 PR 4 - the project-level strip (`strip_project_to_js`) moves into `bynk-driver`, and `bynk-strip` drops its `bynk-emit` dependency to become a leaf on `oxc` (no output change) |
| **v0.510.17** | CI runs the Linux suite as parallel unit+integration and system jobs, with the TS7 re-run in a job of its own |
| **v0.510.16** | Crate hygiene D1 PR 3 - `bynk_emit::project` moves into `bynk-driver` (`bynk_driver::project`); `bynk-emit` is code generation from a checked program (no output change) |
| **v0.510.15** | Crate hygiene D1 PR 2 - `bynk-emit`'s test-emission module `tests_emit.rs` (11.8k lines) is split into ten domain modules under `project/tests_emit/`, with their unit tests (no output change) |
| **v0.510.14** | comment_slots: stale KNOWN rules are judged on totals across shards, and each shard reads only its own pins |
| **v0.510.13** | Crate hygiene D1 PR 1 - the code generator's shared model moves out of `project.rs` into `bynk-emit`'s `emit_model` module, and the `emitter` helpers the orchestration layer uses become a public API (no output change) |
| **v0.510.12** | The bynk-tests corpus is grouped into integration/ and system/ tiers, with one nextest profile per tier and a probe that every test is in exactly one |
| **v0.510.11** | The docs and index consistency checks (and the grammar-reference renderer) move from the integration corpus to xtask |
| **v0.510.10** | The `bynkc/tests` corpus and `bynk-grammar` move into one unpublished `bynk-tests` crate; test commands become `-p bynk-tests --test it` |
| **v0.510.9** | bynk-fmt's comment-slot corpus test runs as eight parallel shards instead of one |
| **v0.510.8** | Internal - a gated `unused_deps` probe in `greenfield-status` fails CI on a declared dependency with no use |
| **v0.510.7** | Internal - drop three unused dependency edges (`bynk-emit` and `bynkc` on `serde`, `bynk-lsp` on `tracing-appender`) |
| **v0.510.6** | `bynk-grammar` becomes unpublished (`publish = false`, path-only workspace entry) and leaves both release workflows' crate lists |
| **v0.510.5** | The `bynk-ir` and `bynk-lower` crates announce their final crates.io release; both are superseded by `bynk-model` (crate-hygiene B1) |
| **v0.510.4** | The editor's sequence diagram, wire contract and hover read handler kinds from the system model (`bynk_ide::wire_contract::BoundaryKind` is now a re-export of `bynk_ir::IrHandlerKind`, so `BoundaryKind::from_handler` is gone and an HTTP kind's `method` is an `IrHttpMethod`), and a gated `model_readers_beyond_emit` ratchet guards the model's reach (crate-hygiene B1) |
| **v0.510.3** | Internal - the expression printer moves from `bynk-fmt` into `bynk-syntax`; `bynk-check` no longer depends on `bynk-fmt` |
