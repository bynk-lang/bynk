== sweep (Credentials::from_env)
   -> set CLOUDFLARE_API_TOKEN and CLOUDFLARE_ACCOUNT_ID to sweep: an API token with "Workers Scripts: Edit" (the listings need read access, and `wrangler` uses the same token to set and delete the sweep's key) and the account it belongs to
== Hyperdrive
   -> set CLOUDFLARE_API_TOKEN and CLOUDFLARE_ACCOUNT_ID to create or update a Hyperdrive config: an API token with "Hyperdrive: Edit" (a `wrangler login` session is not enough: the deploy calls Cloudflare's API directly) and the account it belongs to

== account listings

== email senders
