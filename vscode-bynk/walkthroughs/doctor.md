## Check your setup

**Bynk: Doctor** runs `bynk doctor` and shows whether this machine is ready to
compile, test, serve and deploy Bynk, one group per capability.

Anything missing comes with its remedy. You can run a remedy's command in a
terminal (you confirm it first, and watch it run), open the setting that fixes
it, or copy it. **Check again** re-runs the checks once you've fixed something.

You don't need to run it up front. When a test run, a debug session or the dev
server fails because a tool is missing, its error offers **Run Doctor**.
